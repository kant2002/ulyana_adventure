Бродилка
========

Пустое приложение на Svelte, TypeScript и Vite.

Игрок перемещается кнопками под картой или клавишами-стрелками. При движении
влево и вправо отображается анимация персонажа; камера следует за игроком.

```sh
npm install
npm run dev
```

Для проверки типов и сборки используйте `npm run check` и `npm run build`.

Сборка автоматически использует корневой base path локально и `/ulyana_adventure/`
при деплое в GitHub Pages через GitHub Actions.
